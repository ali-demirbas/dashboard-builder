# Changelog

## 0.3.0

- Routing by request type: analysis, diagnosis and reconciliation requests are answered directly with no template or format question; a named or single fitting dashboard template is built in the same response.
- Statistics: tests chosen by data structure; question 2 of the insight gate reports SUPPORTED / NEGLIGIBLE / INCONCLUSIVE / UNTESTED, and "not significant" is never written as "no effect".
- One label vocabulary: data-quality severity, finding priority, performance direction and claim type kept as separate fields; priority shown as text, never color or emoji.
- Design system tokens for dashboards and decks; template states Supported / Limited / Not supported.
- Repository audit: stale internal docs removed, maintenance docs translated to English, validator now diffs the consolidated file against a fresh rebuild, regression suite extended with ten cases.

## 0.2.0

- Audited decision-logic fixes: insight-gate question wording, comparability hard blocks vs side-by-side reconciliation, confidence and evidence-tier rules, cross-file consistency.
- Consolidated file generated by verbatim concatenation of the source files.

## 0.1.0

- Initial release: data-quality gate, session metric registry, comparability engine, insight candidate engine, 11 dashboard templates, presentation output.
